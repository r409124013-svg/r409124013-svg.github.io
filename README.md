# 🚀 Raghad Abu Aziz — Professional Engineering Portfolio

A modern, responsive, high-performance web portfolio engineered for **Raghad Abu Aziz**, Full-Stack Software Engineer & Computer Systems Engineer.

---

## 🌟 Key Features

- **Modern Tech Aesthetic**: Built with dark-mode first design, gradient accents, and clean typography.
- **Full Responsiveness**: Seamless experience across smartphones, tablets, laptops, and ultra-wide screens.
- **Dynamic Project Filtering**: Filter projects in real-time across *Full-Stack & Web*, *Databases & Architecture*, *Embedded & IoT*, and *OOP & AI*.
- **Interactive Project Modals**: Deep-dive architecture breakdowns using native HTML5 `<dialog>` for fast performance and accessibility.
- **Dark / Light Theme Switcher**: Toggle theme with instant local persistence (`localStorage`).
- **One-Click Email Copying**: Interactive clipboard tooltips for easy employer contact.
- **Academic Timeline**: Structured chronological narrative showcasing 5 years of engineering rigor.
- **Zero Heavy Dependencies**: Pure semantic HTML5, modern CSS3 (Custom properties, Flexbox, Grid), and vanilla ES6+ JavaScript.

## 🚀 How to Run Locally

You can run the portfolio right away without installing any complex dependencies:

1. **Directly in Browser**: Double-click `index.html` to open it in Chrome, Edge, or Firefox.
2. **Via Local Server (Optional)**:
   ```bash
   # Using Python:
   python -m http.server 8000
   # Then open: http://localhost:8000
   ```

## 🌐 How to Publish for Free to GitHub Pages (2 Minutes)

1. Create a new repository on your GitHub account named: `raghad-portfolio` (or `r409124013-svg.github.io`).
2. In your terminal inside this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/r409124013-svg/raghad-portfolio.git
   git push -u origin main
   ```
3. Go to your repository on GitHub:
   - Navigate to **Settings** > **Pages**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your website will be live at `https://r409124013-svg.github.io/raghad-portfolio/`!
